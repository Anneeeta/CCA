# CCA research artifacts

The [2026-10-25 release](2026-10-25/README.md) contains the data supporting the
CCA manuscript's three-system benchmark, five component ablations, generation
token comparison, and paired human evaluation. It includes accepted judge
responses, archived evaluation inputs, generation trajectories, de-identified
human ratings, the executed scoring prompts, and offline statistical analyses.

The [2026-10-30 baseline release](2026-10-30-baselines/README.md) adds the
100 selected OmniThink runs, 100 selected OpenDeepSearch + ReAct runs, and
the second group's anonymous evaluation requests, responses, scores, usage,
source indexes, and reproducible statistics. Each evaluation presents CCA and
the two baselines in a shuffled order; scores are interpreted within their
evaluation group.

The core application remains in the repository root. The 2026-10-25 release
does not include paid experiment runners, batch drivers, or test programs;
the later baseline release includes archived execution scripts.
